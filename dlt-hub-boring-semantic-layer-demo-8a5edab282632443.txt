# BSL: A Boring Semantic Layer for the Sakila Dataset

This repository showcases a complete, end-to-end **semantic layer built on top of the Sakila database**—the classic sample movie-rental dataset—using **dlt** and the **Boring Semantic Layer** libraries. The goal is to provide a **simple, easy-to-follow** example of how to build a semantic layer and reuse it across multiple downstream applications.

With a semantic layer in place, every downstream consumer—APIs, Streamlit apps, chatbots, ER-diagram generators, materializers, and more—can access the same unified data model using intuitive concepts like **dimensions**, **measures**, and **filters**.

This project demonstrates how to:

- Load and normalize source data using **dlt**
- Enrich tables and columns with semantic metadata
- Transform and prepare data for analysis
- Auto-generate a semantic model using an LLM
- Build a fully operational semantic layer (dimensions, measures, joins)
- Reuse that layer across multiple downstream applications, including:
  - A Streamlit data explorer  
  - A FastAPI query interface  
  - A chatbot  
  - An ER-diagram generator  
  - A materializer for creating derived tables in your warehouse

# 💾 Running the pipeline

The entrypoint is:

```bash
uv run python pipeline.py
```

### Available flags
| Flag | Meaning |
|------|---------|
| `--nested-rental`| Loads a deeply nested version of rentals <-- do not use | 
| `--transform` `-t` | Runs custom transformations (PII removal, date handling) |
| `--infer-schema` `-i` | Uses OpenAI to infer a semantic model + generate ERD |

### Example with full flow:
```bash
uv run python pipeline.py -t -i 
```

This will:
1. Load all data into DuckDB
2. Apply transformations
3. Infer semantic model with LLM
4. Generate `semantic_model.json`
5. Render an ER diagram (`diagram.png`)
6. Let you choose to apply the model

# 🧠 How the semantic model works

There are two options for building the semantic layer:

### ✅ **LLM‑Generated Semantic Model** (Recommended and default unless you change code)
Files involved:
- `semantics/llm.py`
- `semantics/model_llm.py`
- `semantics/semantic_model.json`

This mode:
1. Reads the loaded dlt schema which contains database metadata (if present) and column hints (if present)
2. Sends metadata to OpenAI
3. Receives back structured semantic metadata
4. Builds a full semantic model compatible with Boring Semantic Layer

### 📝 **Manual / Schema‑Annotation Semantic Model** (do not use)
Files involved:
- `semantics/model.py`
- `semantics/columns.py`
- manual `x-annotation-...` hints

This mode derives semantics purely from schema annotations.

Any semantic query can be written back into the destination database.
This interface is not great, this should generally happen from the streamlit report.

Example:
```bash
uv run python bsl/downstream_apps/materializer.py -t my_table
```

This executes:
```python
def materialize(pipeline, semantic_model, table_name):
    @dlt.resource(name=table_name, write_disposition="replace")
    def create():
        yield semantic_model.execute()
    pipeline.run(create())
```

from pathlib import Path
import os
import subprocess
import webbrowser
import sys


def safe_open_image(path: Path) -> None:
    """Open a file using the system default viewer, with graceful fallback."""

    if not path.exists():
        print(f"File does not exist: {path}")
        return

    if path.suffix != ".png":
        print(f"Refusing to open file: {path}")
        print("Only .png images are allowed.")
        return

    try:
        if sys.platform.startswith("darwin"):  # macOS
            result = subprocess.call(["open", path])
            if result != 0:
                raise RuntimeError("macOS 'open' failed")

        elif os.name == "nt":  # Windows
            os.startfile(path)  # type: ignore[attr-defined]

        elif os.name == "posix":  # Linux/BSD
            result = subprocess.call(["xdg-open", path])
            if result != 0:
                raise RuntimeError("xdg-open failed")

        else:
            raise RuntimeError("Unsupported platform")

        return

    except Exception as e:
        print(f"Could not open using system viewer: {e}")
        print("Falling back to opening in browser…")
        uri = path.resolve().as_uri()
        webbrowser.open(uri)

from constants import PIPELINE_NAME
from typing import Any
import argparse
import dlt


def remove_pii(ibis_table, schema):
    pii_columns = [
        name for name, col_schema in schema.items()
        if col_schema.get("x-annotation-pii")
    ]

    for column_name, column_schema in schema.items():
        if column_schema.get("x-annotation-pii"):
            pii_columns.append(column_name)
    
    cols_to_drop = [ibis_table[col] for col in pii_columns]
    
    return ibis_table.drop(cols_to_drop)


@dlt.hub.transformation(
    name="dim_customer", write_disposition="replace", primary_key="customer_id"
)
def dim_customer(dataset: dlt.Dataset) -> Any:
    table_name = "dim_customer" if "dim_customer" in dataset.tables else "customer"
    customer = dataset.table(table_name)
    customer_ibis = customer.to_ibis()

    anonymized = remove_pii(customer_ibis, customer.schema["columns"])

    INTERNAL_CUSTOMER_IDS = [1, 2]

    yield anonymized.filter(~anonymized.customer_id.isin(INTERNAL_CUSTOMER_IDS))


@dlt.hub.transformation(
    name="fact_rental",
    write_disposition="replace",
    primary_key="rental_id",
    columns={
        "rental_date": {"data_type": "date"},
        "return_date": {"data_type": "date"},
        "year": {"data_type": "bigint"},
    },
)
def fact_rental(dataset: dlt.Dataset) -> Any:
    rental = dataset.table("rental").to_ibis()

    yield (
        rental
        # add time intelligence columns
        .mutate(
            rental_date=rental.rental_date.date(),
            return_date=rental.return_date.date(),
            year=rental.rental_date.year(),
        )
    )


def transform(pipeline: dlt.Pipeline) -> int:
    dataset = pipeline.dataset()

    pipeline.run(
        [
            dim_customer(dataset),
            fact_rental(dataset),
        ],
    )

    print("Transformations applied correctly.")
    return 0


if __name__ == "__main__":
    parser = argparse.ArgumentParser()

    parser.add_argument("-p", "--pipeline", required=False, type=str)

    args = parser.parse_args()

    pipeline = dlt.attach(
        pipeline_name=args.pipeline if args.pipeline else PIPELINE_NAME,
    )

    exit(transform(pipeline))

import streamlit as st
import requests
from openai import OpenAI
import dlt
import subprocess
import time
import atexit
import os


from downstream_apps.mcp_server import  MCP_SERVER_URL


OPENAI_MCP_SERVER_URL = "https://ellis-peptic-brigitte.ngrok-free.dev/mcp"

def is_server_up():
    try:
        requests.get(MCP_SERVER_URL, timeout=2)
        return True
    except Exception:
        return False

def ensure_mcp_running():
    if is_server_up():
        return

    cmd = ["python", "-m", "downstream_apps.mcp_server"]
    proc = subprocess.Popen(
        cmd,
        stdout=subprocess.PIPE,
        stderr=subprocess.STDOUT,
        env=os.environ.copy()
    )
    st.session_state["_mcp_process"] = proc

    for _ in range(20):
        if is_server_up():
            print("✓ MCP server running")
            return
        time.sleep(0.5)

    output = proc.stdout.read().decode("utf-8", errors="replace")
    st.error("MCP server failed to start:\n" + output)
    raise RuntimeError("MCP server failed to start")


def cleanup():
    proc = st.session_state.get("_mcp_process")
    if proc and proc.poll() is None:
        proc.terminate()
        try:
            proc.wait(timeout=3)
        except subprocess.TimeoutExpired:
            proc.kill()

atexit.register(cleanup)


# ------- BEFORE STREAMLIT UI -------
ensure_mcp_running()

# -------------------------------
# CONFIG
# -------------------------------

openai_api_key: str = dlt.secrets.get("openai_api_key")
client = OpenAI(api_key=openai_api_key)
model = "gpt-4.1"

# -------------------------------
# SESSION STATE
# -------------------------------
if "conversation" not in st.session_state:
    st.session_state.conversation = None

if "chat_messages" not in st.session_state:
    st.session_state.chat_messages = []   # local UI history


# -------------------------------
# UI
# -------------------------------
st.set_page_config(page_title="MCP Chat", page_icon="🤖")
st.title("🤖 MCP-Powered Chatbot")

# ---- Re-render FULL chat history every run ----
for msg in st.session_state.chat_messages:
    st.chat_message(msg["role"]).write(msg["content"])


# -------------------------------
# CHAT INPUT
# -------------------------------
user_msg = st.chat_input("Ask a question about your rental data…")

if user_msg:

    # Add user message to local history
    st.session_state.chat_messages.append({
        "role": "user",
        "content": user_msg
    })
    st.chat_message("user").write(user_msg)

    # ---------------------------------------
    # SEND REQUEST TO OPENAI (with MCP)
    # ---------------------------------------
    stream = client.responses.create(
        model=model,
        input=user_msg,
        conversation=st.session_state.conversation,
        tools=[
            {
                "type": "mcp",
                "server_label": "local_rentals",
                "server_url": OPENAI_MCP_SERVER_URL,
                "require_approval": "never",
            }
        ],
        stream=True,
    )

    assistant_box = st.chat_message("assistant")
    placeholder = assistant_box.empty()
    full_text = ""

    final_conversation = None

    # STREAMING
    for event in stream:
        if event.type == "response.output_text.delta":
            full_text += event.delta
            placeholder.write(full_text)

        elif event.type == "response.completed":
            final_conversation = event.response.conversation

    # Save assistant message in history
    st.session_state.chat_messages.append({
        "role": "assistant",
        "content": full_text
    })

    # Update conversation memory
    if final_conversation:
        st.session_state.conversation = final_conversation

            ops = operator_list(field)
            op = st.selectbox(

                key=f"op_{idx}",

                remove_idx = idx

            flt["field"] = field
            flt["op"] = op
            flt["value"] = value

    if remove_idx is not None:
        st.session_state.filters.pop(remove_idx)

else:

with left_col:

from constants import PIPELINE_NAME
from semantics.model_llm import create_semantic_model_llm
from boring_semantic_layer import SemanticModel
import argparse
import dlt


def materialize(
    pipeline: dlt.Pipeline,
    semantic_model: SemanticModel,
    table_name: str,
) -> int:

    @dlt.resource(name=table_name, write_disposition="replace")
    def create():
        yield semantic_model.execute()

    pipeline.run(
        create(),
    )

    return 0

if __name__ == "__main__":
    parser = argparse.ArgumentParser()

    parser.add_argument("-p", "--pipeline", required=False, type=str)
    parser.add_argument("-t", "--table-name", required=False, type=str)

    args = parser.parse_args()

    pipeline = dlt.attach(
        pipeline_name=args.pipeline if args.pipeline else PIPELINE_NAME,
    )

    model = create_semantic_model_llm(pipeline)

    query = (
        model
            .group_by("dim_film__title")
            .aggregate("total_rentals", "unique_customers")
    )

    table_name = "test"

    materialize(
        pipeline,
        query,
        args.table_name if args.table_name else table_name,
    )

from pydantic import BaseModel, Field
from typing import List, Optional, Any


class JsonDataResponse(BaseModel):
    data: Any


class FilterCondition(BaseModel):
    """A single filter condition."""
    field: str = Field(..., examples=["dim_country"])
    op: str = Field(..., examples=["="])
    value: str = Field(..., examples=["France"])


class QueryRequest(BaseModel):
    """Semantic query request."""
    dimensions: Optional[List[str]] = Field(
        default=None,
        description="A list of dimension names to group by.",
        examples=["dim_country", "dim_staff__gender"]
    )
    measures: List[str] = Field(
        ...,
        description="A list of measure names to aggregate.",
        examples=["rentals_count"]
    )
    filters: Optional[List[FilterCondition]] = Field(
        default=None,
        description="A list of filter conditions."
    )

    model_config = {
        "json_schema_extra": {
            "example": {
                "dimensions": [
                    "dim_customer__create_date",
                    "dim_country__via__dim_customer__country"
                ],
                "measures": [
                    "rentals_count",
                    "unique_customers"
                ],
                "filters": [
                    {
                        "field": "dim_film__title",
                        "op": "contains",
                        "value": "A"
                    },
                    {
                        "field": "dim_customer__active",
                        "op": "=",
                        "value": "active"
                    }
                ]
            }
        }
    }

from fastapi import FastAPI, Header, Response
from constants import PIPELINE_NAME
from downstream_apps.api.models import QueryRequest, JsonDataResponse
from semantics.model_llm import create_semantic_model_llm
from semantics.query_builder import build_semantic_query
import dlt
import io
import pyarrow as pa
import pandas as pd


pipeline = dlt.attach(
    pipeline_name=PIPELINE_NAME,
)

model = create_semantic_model_llm(pipeline)

dims = model.get_dimensions()
meas = model.get_measures()

app = FastAPI()


@app.get(
    "/dimensions",
    response_model=JsonDataResponse,
    summary="List all dimensions",
    description="Returns all dimension names with descriptions.",
    responses={
        200: {
            "content": {
                "application/json": {
                    "example": {
                        "data": {
                            "dim_country": "Country name",
                            "dim_staff__gender": "Gender of staff"
                        }
                    }
                }
            }
        }
    }
)
def get_dimensions():
    return JsonDataResponse(data={k: v.description for k, v in dims.items()})


@app.get(
    "/measures",
    response_model=JsonDataResponse,
    summary="List all measures",
    description="Returns all measure names with descriptions.",
    responses={
        200: {
            "content": {
                "application/json": {
                    "example": {
                        "data": {
                            "avg_salary": "Average salary",
                            "total_revenue": "Total revenue"
                        }
                    }
                }
            }
        }
    }
)
def get_measures():
    return JsonDataResponse(data={k: v.description for k, v in meas.items()})


@app.post(
    "/query",
    summary="Run a semantic query",
    responses={
        200: {
            "content": {
                "application/json": {
                    "example": [{"dim_country": "France", "avg_salary": 55000}]
                },
                "application/parquet": {
                    "schema": {
                        "type": "string",
                        "format": "binary"
                    }
                },
            },
            "description": "JSON or Parquet results depending on the Accept header."
        }
    }
)
def run_query(
    query_request: QueryRequest,
    accept: str | None = Header(None)
):
    query = build_semantic_query(
        model,
        query_request,
    )

    df: pd.DataFrame = query.execute()

    parquet = accept and "application/parquet" in accept

    if parquet:
        buffer = io.BytesIO()
        table = pa.Table.from_pandas(df)
        pa.parquet.write_table(table, buffer)

        return Response(
            content=buffer.getvalue(),
            media_type="application/parquet",
            headers={"Content-Disposition": "attachment; filename=data.parquet"}
        )
    
    return JsonDataResponse(data=df.to_dict(orient="records"))

CREATE PROCEDURE rewards_report (
    IN min_monthly_purchases TINYINT UNSIGNED
    , IN min_dollar_amount_purchased DECIMAL(10,2)
    , OUT count_rewardees INT
)
LANGUAGE SQL
NOT DETERMINISTIC
READS SQL DATA
SQL SECURITY DEFINER
COMMENT 'Provides a customizable report on best customers'
proc: BEGIN

    DECLARE last_month_start DATE;
    DECLARE last_month_end DATE;

    /* Some sanity checks... */
    IF min_monthly_purchases = 0 THEN
        SELECT 'Minimum monthly purchases parameter must be > 0';
        LEAVE proc;
    END IF;
    IF min_dollar_amount_purchased = 0.00 THEN
        SELECT 'Minimum monthly dollar amount purchased parameter must be > $0.00';
        LEAVE proc;
    END IF;

    /* Determine start and end time periods */
    SET last_month_start = DATE_SUB(CURRENT_DATE(), INTERVAL 1 MONTH);
    SET last_month_start = STR_TO_DATE(CONCAT(YEAR(last_month_start),'-',MONTH(last_month_start),'-01'),'%Y-%m-%d');
    SET last_month_end = LAST_DAY(last_month_start);

    /*
        Create a temporary storage area for
        Customer IDs.
    */
    CREATE TEMPORARY TABLE tmpCustomer (customer_id SMALLINT UNSIGNED NOT NULL PRIMARY KEY);

    /*
        Find all customers meeting the
        monthly purchase requirements
    */
    INSERT INTO tmpCustomer (customer_id)
    SELECT p.customer_id
    FROM payment AS p
    WHERE DATE(p.payment_date) BETWEEN last_month_start AND last_month_end
    GROUP BY customer_id
    HAVING SUM(p.amount) > min_dollar_amount_purchased
    AND COUNT(customer_id) > min_monthly_purchases;

    /* Populate OUT parameter with count of found customers */
    SELECT COUNT(*) FROM tmpCustomer INTO count_rewardees;

    /*
        Output ALL customer information of matching rewardees.
        Customize output as needed.
    */
    SELECT c.*
    FROM tmpCustomer AS t
    INNER JOIN customer AS c ON t.customer_id = c.customer_id;

    /* Clean up */
    DROP TABLE tmpCustomer;
END //

CREATE FUNCTION get_customer_balance(p_customer_id INT, p_effective_date DATETIME) RETURNS DECIMAL(5,2)
    DETERMINISTIC
    READS SQL DATA
BEGIN

       #OK, WE NEED TO CALCULATE THE CURRENT BALANCE GIVEN A CUSTOMER_ID AND A DATE
       #THAT WE WANT THE BALANCE TO BE EFFECTIVE FOR. THE BALANCE IS:
       #   1) RENTAL FEES FOR ALL PREVIOUS RENTALS
       #   2) ONE DOLLAR FOR EVERY DAY THE PREVIOUS RENTALS ARE OVERDUE
       #   3) IF A FILM IS MORE THAN RENTAL_DURATION * 2 OVERDUE, CHARGE THE REPLACEMENT_COST
       #   4) SUBTRACT ALL PAYMENTS MADE BEFORE THE DATE SPECIFIED

  DECLARE v_rentfees DECIMAL(5,2); #FEES PAID TO RENT THE VIDEOS INITIALLY
  DECLARE v_overfees INTEGER;      #LATE FEES FOR PRIOR RENTALS
  DECLARE v_payments DECIMAL(5,2); #SUM OF PAYMENTS MADE PREVIOUSLY

  SELECT IFNULL(SUM(film.rental_rate),0) INTO v_rentfees
    FROM film, inventory, rental
    WHERE film.film_id = inventory.film_id
      AND inventory.inventory_id = rental.inventory_id
      AND rental.rental_date <= p_effective_date
      AND rental.customer_id = p_customer_id;

  SELECT IFNULL(SUM(IF((TO_DAYS(rental.return_date) - TO_DAYS(rental.rental_date)) > film.rental_duration,
        ((TO_DAYS(rental.return_date) - TO_DAYS(rental.rental_date)) - film.rental_duration),0)),0) INTO v_overfees
    FROM rental, inventory, film
    WHERE film.film_id = inventory.film_id
      AND inventory.inventory_id = rental.inventory_id
      AND rental.rental_date <= p_effective_date
      AND rental.customer_id = p_customer_id;


  SELECT IFNULL(SUM(payment.amount),0) INTO v_payments
    FROM payment

    WHERE payment.payment_date <= p_effective_date
    AND payment.customer_id = p_customer_id;

  RETURN v_rentfees + v_overfees - v_payments;
END $$

    DECLARE v_rentals INT;

    SELECT COUNT(*) INTO v_rentals
    FROM rental
    WHERE inventory_id = p_inventory_id;

      RETURN TRUE;

    FROM inventory LEFT JOIN rental USING(inventory_id)

from dlt.common.schema.typing import TTableSchemaColumns
from typing import Literal, get_args, TypedDict, Any, List, Dict


ColumnSemanticType = Literal["dimension", "filter", "measure"]


class ColumnSemanticData(TypedDict):
    header: str
    column_semantic_data: List[Any]


TableSemanticData = Dict[ColumnSemanticType, ColumnSemanticData]


def extract_semantic_column_data(
    table_column_schema: TTableSchemaColumns,
) -> TableSemanticData:
    table_semantic_data: TableSemanticData = {
        key: {"header": f"x-annotation-{key}", "column_semantic_data": []}
        for key in get_args(ColumnSemanticType)
    }

    for column_name, column_schema in table_column_schema.items():
        for semantic_type, semantic_type_data in table_semantic_data.items():
            header = semantic_type_data["header"]
            if header not in column_schema:
                continue

            if semantic_type == "measure":
                column_semantic_data = {
                    column_name: column_schema[header]  # type: ignore
                }
                table_semantic_data[semantic_type]["column_semantic_data"].append(
                    column_semantic_data
                )
            else:
                # this gets dimensions and filters
                table_semantic_data[semantic_type]["column_semantic_data"].append(
                    column_name
                )

    return table_semantic_data

IbisAgg = Literal[
    "sum",
    "mean",
    "min",
    "max",
    "count",
    "nunique",
    "std",
    "var",
    "median",
]


class MeasureCandidate(BaseModel):
    measure_name: str
    description: Optional[str] = Field(description="Very brief applied description of the meaning of the measure if not obvious.")
    source_column: str
    aggregation: IbisAgg
    ibis_filter_expr: Optional[str] = Field(
        None,
        description=(
            "Ibis lambda expression returning a boolean filter. "
            "Example: \"lambda t: t.status == 'active'\""
        ),
    )


class Reference(BaseModel):
    referenced_table: str
    fk_columns: List[str]
    pk_columns: List[str]
    cardinatlity: TReferenceCardinality

    def as_table_reference(self) -> TTableReference:
        return TTableReference(
            cardinality=self.cardinatlity,
            referenced_table=self.referenced_table,
            columns=self.fk_columns,
            referenced_columns=self.pk_columns,
        )


class FactTable(BaseModel):
    table_name: str
    source_table: str
    primary_key: str
    measure_candidates: List[MeasureCandidate]
    references: Optional[List[Reference]] = None

    dimension_name: str
    description: Optional[str] = Field(description="Very brief applied description of the meaning of the dimension if not obvious.")
    source_column: str
    ibis_bucketing_expr: Optional[str] = Field(
        None,
        description=(
            "Ibis lambda expression that takes t (the dimension source table) "
            "and returns a derived column expression for bucketing. "
            "Only for dimensions where it makes sense bucketing to group values, not for the ones with very high cardinality.  "

class Dimension(BaseModel):
    table_name: str
    source_table: str

def _prefix_columns(table, table_name: str):

        for col in table.columns
        if col not in ("_dlt_id", "_dlt_load_id")

def _build_dimension_measure_bsl_kwargs(
    table_name: str,
    table_semantic_data: TableSemanticData,
):
    dimension_kwargs = {
        col: (lambda t, c=f"{table_name}__{col}": t[c])
        for col in table_semantic_data["dimension"]["column_semantic_data"]
    }

    measure_kwargs = {
        f"{col}_{agg}": (
            lambda t, col=f"{table_name}__{col}", agg=agg: getattr(t[col], agg)()
        )
        for item in table_semantic_data["measure"]["column_semantic_data"]
        for col, agg in item.items()
    }

    return dimension_kwargs, measure_kwargs


def _build_join_lambda(left_table_name, right_table_name, left_cols, right_cols):
    if len(left_cols) != len(right_cols):
        raise ValueError("Join columns mismatch")

    def _join(left, right):
        cond = None
        for lc, rc in zip(left_cols, right_cols):
            left_col = f"{left_table_name}__{lc}"
            right_col = f"{right_table_name}__{rc}"
            c = getattr(left, left_col) == getattr(right, right_col)
            cond = c if cond is None else (cond & c)
        return cond

    return _join


def _recursive_semantic_join(
    semantic_table_references,
    semantic_table_references_copy,
    semantic_model,
    semantic_model_base,
    referencing_table,
) -> SemanticModel:
    references = semantic_table_references_copy[referencing_table]

    if not references or len(references) == 0:
        return semantic_model

    del semantic_table_references_copy[referencing_table]

    for reference in references:
        referenced_table = reference["referenced_table"]
        if referenced_table not in semantic_model_base:
            raise RuntimeError(f"Referenced table '{referenced_table}' was not loaded")

        on_clause = _build_join_lambda(
            referencing_table,
            reference["referenced_table"],
            reference["columns"],
            reference["referenced_columns"],
        )

        semantic_model = semantic_model.join(
            semantic_model_base[referenced_table],
            on=on_clause,
            how="left",
        )

        semantic_model = _recursive_semantic_join(
            semantic_table_references,
            semantic_table_references_copy,
            semantic_model,
            semantic_model_base,
            referenced_table,
        )

    return semantic_model


def _build_semantic_relationships(
    semantic_model_base: Dict[str, SemanticModel],
    semantic_table_references: Dict[str, List[TableReference]],
) -> SemanticModel:
    for referencing_table in semantic_table_references.keys():
        if referencing_table.startswith("fact_"):
            root = referencing_table
            break

    semantic_model = semantic_model_base[root]

    import copy

    semantic_table_references_copy = copy.deepcopy(semantic_table_references)

    semantic_model = _recursive_semantic_join(
        semantic_table_references,
        semantic_table_references_copy,
        semantic_model,
        semantic_model_base,
        root,
    )

    return semantic_model


def create_semantic_model(
    pipeline: dlt.Pipeline,
) -> SemanticModel:
    semantic_table_references = get_semantic_table_references()

    default_schema_tables = pipeline.default_schema.tables

    for referencing_table, reference_details in semantic_table_references.items():
        # Materialize the references in the schema
        table_reference_adapter(
            pipeline, referencing_table, references=reference_details
        )

    # this base model will only have the dimensions and metrics per table, without relationships
    semantic_model_base: Dict[str, SemanticModel] = {}

    for table_name in default_schema_tables.keys():
        if not table_name.startswith("dim_") and not table_name.startswith("fact_"):
            continue

        table_semantic_data = extract_semantic_column_data(
            pipeline.default_schema.get_table_columns(table_name)
        )

        dimension_kwargs, measure_kwargs = _build_dimension_measure_bsl_kwargs(
            table_name, table_semantic_data
        )

        table = (
            pipeline.dataset()
            .table(table_name)
            .to_ibis()
            .drop(["_dlt_id", "_dlt_load_id"])
        )
        table = _prefix_columns(table, table_name)

        st = (
            to_semantic_table(table)
            .with_dimensions(**dimension_kwargs)
            .with_measures(**measure_kwargs)
        )

        semantic_model_base[table_name] = st

    return _build_semantic_relationships(
        semantic_model_base,
        semantic_table_references,
    )

def rewrite_expr_to_alias(expr: str, alias: str) -> str:
    # 1. replace t.col with t["alias__col"]
    pattern = r"t\.([A-Za-z_][A-Za-z0-9_]*)"

    def repl(match):
        col = match.group(1)
        return f't["{alias}__{col}"]'

    rewritten = re.sub(pattern, repl, expr)

    # 2. normalize null-check functions
    rewritten = (
        rewritten
        .replace(".isnotnull()", ".notnull()")
        .replace(".is_null()", ".isnull()")
        .replace(".is_not_null()", ".notnull()")
    )

    return rewritten


def build_alias_map(semantic_json_model):
    """
    Returns:
        alias_by_path: dict keyed by (table_name, path_tuple)
        Each value is a unique alias following these rules:
          - Fact table keeps its name
          - Tables with a single parent keep their name
          - Tables with >1 parents get name__via__parent
          - Downstream tables inherit the bifurcation prefix
    """

    from collections import defaultdict, deque

    root = semantic_json_model.fact_table.table_name

    # ----------------------------------------------------
    # 1. Build graph of parents
    # ----------------------------------------------------
    parents = defaultdict(set)
    graph = defaultdict(list)

    # BFS to gather graph structure
    q = deque([(semantic_json_model.fact_table, root)])

    while q:
        block, parent_name = q.popleft()
        table_name = block.table_name

        if block != semantic_json_model.fact_table:
            parents[table_name].add(parent_name)

        for ref in block.references or []:
            child = next(
                d for d in semantic_json_model.dimensions
                if d.table_name == ref.referenced_table
                or d.source_table == ref.referenced_table
            )

            graph[table_name].append(child.table_name)
            q.append((child, table_name))

    # ----------------------------------------------------
    # 2. Second BFS: assign aliases with inherited bifurcation
    # ----------------------------------------------------
    alias_by_path = {}
    q = deque([(semantic_json_model.fact_table, (), None, None)])

    alias_by_path[(root, ())] = root

    while q:
        block, path, parent, inherited_bifurcation = q.popleft()
        table_name = block.table_name

        # Determine if this table bifurcates
        is_bifurcation = len(parents[table_name]) > 1

        # Determine this node's bifurcation tag
        if inherited_bifurcation is not None:
            bifurcation_tag = inherited_bifurcation
        elif is_bifurcation and parent is not None:
            bifurcation_tag = parent
        else:
            bifurcation_tag = None

        # Build alias
        if bifurcation_tag is None:
            alias = table_name
        else:
            alias = f"{table_name}__via__{bifurcation_tag}"

        alias_by_path[(table_name, path)] = alias

        # Explore children
        for child_name in graph[table_name]:
            child_block = next(
                d for d in semantic_json_model.dimensions if d.table_name == child_name
            )
            child_path = path + (table_name,)
            q.append((child_block, child_path, table_name, bifurcation_tag))

    path_by_alias = {alias: path for (_, path), alias in alias_by_path.items()}

    return alias_by_path, path_by_alias


def _build_dimension_measure_bsl_kwargs_for_alias(dataset_table, table_block, alias):
    prefix = alias + "__"  # for column names only

    dimension_kwargs = {}
    measure_kwargs = {}

    # dimensions
    if hasattr(table_block, "dimension_candidates"):
        for dim in table_block.dimension_candidates:
            if dim.source_column not in dataset_table.columns:
                continue

            col = dim.source_column
            full_col = prefix + col

            dim_name = f"{alias}__{col}"

            if dim.ibis_bucketing_expr:
                expr_str = rewrite_expr_to_alias(dim.ibis_bucketing_expr, alias)
                bucket_expr = eval(expr_str)

                dimension_kwargs[dim_name] = Dimension(
                    expr=lambda t, bl=bucket_expr: bl(t),
                    description=dim.description,
                )

            else:
                # Simple column dimension
                dimension_kwargs[dim_name] = Dimension(
                    expr=lambda t, fc=full_col: t[fc],
                    description=dim.description,
                )

    # measures stay global — do not namespace them
    if hasattr(table_block, "measure_candidates"):
        for mc in table_block.measure_candidates:
            col = mc.source_column
            full_col = prefix + col
            agg = mc.aggregation

            if mc.ibis_filter_expr:
                expr_str = rewrite_expr_to_alias(mc.ibis_filter_expr, alias)
                filt = eval(expr_str)

                def _measure(t, fc=full_col, agg=agg, filt=filt):
                    col = t[fc]
                    func = getattr(col, agg)

                    # IMPORTANT: use the Ibis filtered agg API
                    return func(where=filt(t))

                measure_kwargs[mc.measure_name] = Measure(
                    expr=_measure,
                    description=mc.description,
                )

            # Simple aggregated measure
            else:
                measure_kwargs[mc.measure_name] = Measure(
                    expr=lambda t, fc=full_col, agg=agg: getattr(t[fc], agg)(),
                    description=mc.description,
                )

    return dimension_kwargs, measure_kwargs


def _build_join_lambda(left_alias, right_alias, left_cols, right_cols):
    def _join(left, right):
        cond = None
        for lc, rc in zip(left_cols, right_cols):
            left_col = f"{left_alias}__{lc}"
            right_col = f"{right_alias}__{rc}"
            c = getattr(left, left_col) == getattr(right, right_col)
            cond = c if cond is None else (cond & c)
        return cond

    return _join


def _recursive_semantic_join(
    semantic_table_references,
    visited,
    semantic_model,
    semantic_model_base,
    referencing_alias,
    alias_map,
    path_map,
) -> SemanticModel:
    if referencing_alias in visited:
        return semantic_model

    visited.add(referencing_alias)

    referencing_table = referencing_alias.split("__via__")[0]

    references = semantic_table_references.get(referencing_table, [])

    for reference in references:
        referenced_table = reference["referenced_table"]

        # Retrieve full path for this edge
        full_path = path_map[referencing_alias] + (referencing_table,)

        # Resolve child alias using path
        referenced_alias = alias_map.get((referenced_table, full_path))

        if referenced_alias is None:
            raise RuntimeError(
                f"Alias lookup failed for {referenced_table} with path {full_path}"
            )

        if referenced_alias not in semantic_model_base:
            raise RuntimeError(f"Alias '{referenced_alias}' missing in model base")

        on_clause = _build_join_lambda(
            referencing_alias,
            referenced_alias,
            reference["columns"],
            reference["referenced_columns"],
        )

        semantic_model = semantic_model.join(
            semantic_model_base[referenced_alias],
            on=on_clause,
            how="left",
        )

        semantic_model = _recursive_semantic_join(
            semantic_table_references,
            visited,
            semantic_model,
            semantic_model_base,
            referenced_alias,
            alias_map,
            path_map,
        )

    return semantic_model


def _build_semantic_relationships(
    semantic_model_base,
    semantic_table_references,
    alias_map,
    path_map,
):
    root_alias = alias_map[(list(alias_map.keys())[0][0], ())]

    visited = set()

    root_model = semantic_model_base[root_alias]

    return _recursive_semantic_join(
        semantic_table_references,
        visited,
        root_model,
        semantic_model_base,
        root_alias,
        alias_map,
        path_map,
    )


def create_semantic_model_llm(
    pipeline: dlt.Pipeline,
) -> SemanticModel:
    semantic_json_model = SemanticModelsWrapper.model_validate_json(
        Path(MODEL_FILE).read_text()
    ).semantic_models[0]

    semantic_table_references: Dict[str, List[TableReference]] = {}

    fact_tbl = semantic_json_model.fact_table
    semantic_table_references[fact_tbl.table_name] = [
        ref.as_table_reference() for ref in (fact_tbl.references or [])
    ]

    for dim in semantic_json_model.dimensions or []:
        semantic_table_references[dim.table_name] = [
            ref.as_table_reference() for ref in (dim.references or [])
        ]

    # Materialize the references into the schema
    for table_name, refs in semantic_table_references.items():
        table_reference_adapter(
            pipeline,
            table_name,
            references=refs,
        )

    # this base model will only have the dimensions and metrics per table, without relationships
    semantic_model_base: Dict[str, SemanticModel] = {}
    alias_map, path_map = build_alias_map(semantic_json_model)

    for (original_name, _), semantic_name in alias_map.items():
        table_block: FactTable | DimTable
        if original_name == semantic_json_model.fact_table.table_name:
            table_block = semantic_json_model.fact_table
        else:
            table_block = next(
                dim
                for dim in semantic_json_model.dimensions
                if dim.table_name == original_name
            )

        physical_table_name = table_block.source_table
        dataset_table = pipeline.dataset().table(physical_table_name)

        # build dimension & measure kwargs
        dimension_kwargs, measure_kwargs = (
            _build_dimension_measure_bsl_kwargs_for_alias(
                dataset_table,
                table_block,
                semantic_name,
            )
        )

        table = (
            dataset_table
            .to_ibis()
            .drop(["_dlt_id", "_dlt_load_id"])
        )
        table = _prefix_columns(table, semantic_name)

        semantic_model_base[semantic_name] = (
            to_semantic_table(table)
            .with_dimensions(**dimension_kwargs)
            .with_measures(**measure_kwargs)
        )

    return _build_semantic_relationships(
        semantic_model_base, semantic_table_references, alias_map, path_map
    )

from downstream_apps.api.models import QueryRequest
from boring_semantic_layer import SemanticModel
import ibis


def build_single_filter(dim_obj, op: str, value: str):
    """Return an ibis predicate based on the semantic model dimension."""
    def _filter(t):
        col = dim_obj.expr(t)
        col_type = col.type()

        # ------------------------------
        # TYPE CAST BASED ON IBIS TYPE
        # ------------------------------
        if col_type.is_string():
            cast_value = str(value)
            target_col = col.fill_null("")
        elif col_type.is_boolean():
            if isinstance(value, str):
                cast_value = value.lower() in ("1", "true", "yes", "t")
            target_col = col
        elif col_type.is_integer():
            cast_value = int(value)
            target_col = col
        elif col_type.is_floating():
            cast_value = float(value)
            target_col = col
        elif col_type.is_timestamp():
            cast_value = ibis.literal(value).cast(col_type)
            target_col = col
        elif col_type.is_date():
            cast_value = ibis.literal(value).cast(col_type)
            target_col = col
        else:
            cast_value = str(value)
            target_col = col.fill_null("")

        # ------------------------------
        # OPERATORS
        # ------------------------------
        ops = {
            "=": target_col == cast_value,
            "!=": target_col != cast_value,
            ">": target_col > cast_value,
            ">=": target_col >= cast_value,
            "<": target_col < cast_value,
            "<=": target_col <= cast_value,
        }

        if op == "contains":
            return target_col.contains(cast_value)

        if op in ops:
            return ops[op]

        raise ValueError(f"Unsupported operator: {op}")

    return _filter


def build_semantic_query(
    model,
    query_request: QueryRequest,
) -> SemanticModel:
    """
    Construct a semantic model query object with:
    - filters applied
    - custom group_by
    - measures applied

    Returns the *query object*, not executed.
    """
    query = model
    dimensions = query_request.dimensions
    measures = query_request.measures
    filters = query_request.filters

    DIMENSIONS = model.get_dimensions()

    # ------------------------------
    # Apply filters
    # ------------------------------
    if filters:
        for f in filters:
            dim_obj = DIMENSIONS[f.field]
            flambda = build_single_filter(
                dim_obj,
                f.op,
                f.value
            )
            query = query.filter(flambda)

    # ------------------------------
    # Aggregations
    # ------------------------------
    if measures:
        if dimensions:
            query = query.group_by(*dimensions).aggregate(*measures)
        else:
            query = query.aggregate(*measures)

    return query

from dlt.extract import DltResource
from dlt.sources.sql_database import sql_table
from sqlalchemy import create_engine, text, URL
import dlt


def get_rental_table_with_hints(nested_rental: bool = False) -> DltResource:
    if not nested_rental:
        rental = sql_table(
            table="rental",
            primary_key="rental_id",
            resolve_foreign_keys=True,
        )
        return rental.apply_hints(
            columns={
                "rental_id": {"x-annotation-measure": "count"},  # type: ignore
                "customer_id": {"x-annotation-measure": "nunique"},  # type: ignore
            }
        )

    @dlt.resource(
        name="customer_rental",
        primary_key="customer_id",
        nested_hints={
            "rentals": dlt.mark.make_nested_hints(
                primary_key="rental_id",
                write_disposition="replace",
                columns={
                    "rental_id": {"x-annotation-measure": "count"},  # type: ignore
                    "customer_id": {"x-annotation-measure": "nunique"},  # type: ignore
                },
            )
        },
        resolve_foreign_keys=True,
    )
    def customer_rental(credentials=dlt.secrets.value):
        import json

        url = URL.create(**credentials)
        engine = create_engine(url)

        with engine.connect() as conn:
            rows = conn.execute(text("SELECT * FROM customer_rentals")).mappings()

            for row in rows:
                row = dict(row)
                row["rentals"] = json.loads(row["rentals"])
                yield row

    def _pushdown_customer_id(row):
        id_ = row["customer_id"]
        for rental in row["rentals"]:
            rental["customer_id"] = id_
        return row

    return customer_rental.add_map(_pushdown_customer_id)

from sqlalchemy import cast, String, Integer, func
from sqlalchemy.dialects import mysql
from typing import List


def sakila_type_adapter(sa_type):
    # MySQL YEAR → integer
    if isinstance(sa_type, mysql.YEAR):
        return Integer()

    # MySQL ENUM → string
    if isinstance(sa_type, mysql.ENUM):
        return String()

    return None


def sakila_query_adapter(select, table, *args, **kwargs):
    new_columns = []

    for col in select.selected_columns:
        # ---- Handle MySQL SET → TEXT (dlt does not support sets)
        if hasattr(col.type, "values"):
            new_columns.append(cast(col, String()).label(col.name))
            continue

        # ---- Handle Geometry POINT → lat/long numeric columns (dlt does not support point/geometry...)
        if isinstance(col.type, Geometry):
            # ST_X = longitude, ST_Y = latitude
            new_columns.append(func.ST_X(col).label(col.name + "_lng"))
            new_columns.append(func.ST_Y(col).label(col.name + "_lat"))
            continue

        new_columns.append(col)

    return select.with_only_columns(*new_columns)
